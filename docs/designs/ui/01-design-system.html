6. Figma File Structure (Recommended)

Organize Figma file into these pages for clean handoff.

CoverProject name, version, date, links

Create as local styles with naming: Surface/bg-0, Text/primary, Semantic/good, Nav/bg, Tag/ok-bg, etc.

6.2 Figma Text Styles

Create text styles matching Section 2: h1-page, h2-section, h3-panel, body, body-sm, btn-label, caption, th-header, tag, stat-value, mono-log.

6.3 Figma Effect Styles
