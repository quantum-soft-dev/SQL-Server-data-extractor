# Phases

Этот набор документов разбивает реализацию проекта на фазы. Каждая фаза имеет короткий overview и точное описание объема работ, артефактов и критериев готовности.

Список:
1) `PHASE-1.md` — MVP end-to-end (snapshot + delta, сервис + Windows App, IPC, базовый API контракт).
2) `PHASE-2.md` — Production hardening (установка/обновления, наблюдаемость, надежность, безопасность, операционка).
3) `PHASE-3.md` — Расширения (эволюция схемы, re-bootstrap UX, оптимизации, дополнительные режимы/политики).
